# ChatLustora - Review for ChatGPT

This folder contains source-code copies for review only.

Purpose:
- Allow ChatGPT to inspect selected source files.
- Review AI Studio changes before production deployment.
- Identify bugs, security issues and regressions.

Rules:
- This folder is NOT production source code.
- Do not store passwords, API keys, tokens or secrets here.
- Preserve original source paths and directory structure.
- Update review_manifest.md when submitting a new review.
